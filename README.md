# 日日食記

繁體中文的個人飲食日誌，使用單一 HTML，無須安裝套件或後端服務。

## 功能

- 依日期記錄早餐、午餐、晚餐與點心。
- 食物、份量、選填熱量與備註。
- 當日熱量與紀錄筆數統計。
- 編輯與刪除紀錄。
- 瀏覽器自動儲存，以及 JSON 備份匯入／匯出。
- 適合手機及電腦的版面。

## 使用

用瀏覽器開啟 `index.html`，或使用發布後的 GitHub Pages 網址。

資料儲存在目前瀏覽器的 localStorage，不會上傳至 GitHub，也不會跨裝置同步。更換網址、裝置或瀏覽器不會自動帶入原有紀錄；請先匯出 JSON 備份，再到新位置匯入。建議定期備份。

## 驗證

使用 Node.js 執行：

```sh
node --test --test-isolation=none diet.test.cjs
```

測試包含按日期加總熱量，以及備份資料驗證。
